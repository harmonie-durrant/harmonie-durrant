## 🚀 Featured projects

### 📚 [wiki42](https://github.com/harmonie-durrant/wiki42) · [Live site ↗](https://wiki42.harmoniedurrant.com)
The unofficial community wiki for current and future 42 students. I built it and maintain it as an open, community-driven project.
`TypeScript` `Next.js` `MDX` · *Product ownership, documentation, community management*

### 🧊 [Voxel Game](https://github.com/harmonie-durrant/voxel-game-threejs) · [Play ↗](https://voxels.harmoniedurrant.com)
A voxel sandbox that runs in the browser, with infinite procedurally generated terrain, inspired by Minecraft.
`TypeScript` `Three.js` `WebGL` · *3D maths, rendering performance, procedural generation*

### 💣 [Harmonie's Infinite Minesweeper](https://github.com/harmonie-durrant/harmonies-infinite-minesweeper) · [Play ↗](https://harmonies-infinite-minesweeper.vercel.app)
Minesweeper on an endless board, with high scores and progression. I also made a [3D version in S&Box](https://github.com/harmonie-durrant/3d-infinite-minesweeper) (C#).
`TypeScript` `Vercel` · *Game logic, state management, deployment*

### 🏠 Home Assistant
I have made various open-source add-ons for Home Assistant that other people install and use:
- **[hha-cards](https://github.com/harmonie-durrant/hha-cards):** customisable dashboard cards, distributed through HACS
- **[harmonie-changelogs](https://github.com/harmonie-durrant/harmonie-changelogs):** a Lovelace card that shows changelogs to users
- **[ha-banking](https://github.com/harmonie-durrant/ha-banking):** an integration that tracks bank account balances
- **[ft_homeassistant](https://github.com/harmonie-durrant/ft_homeassistant):** an integration with the 42 intranet API that adds logtime

`Python` `JavaScript` `Web Components` · *API integration, packaging, maintaining open source*

### 🌐 [ft_irc](https://github.com/harmonie-durrant/ft_irc)
An IRC server written in C++98 by a team of 3. It handles many clients at once on non-blocking sockets and works with real IRC clients.
`C++` `Sockets` `poll()` · *Network protocols, teamwork, event-driven design*

### 🐚 [minishell](https://github.com/harmonie-durrant/minishell-42)
A Bash-like shell with pipes, redirections, heredocs, environment variables and signal handling.
`C` `Unix` · *Parsing, process management, memory safety*

### 🐳 [Inception](https://github.com/harmonie-durrant/inception-42)
A small containerised infrastructure: WordPress, NGINX with TLS and MariaDB, each in its own Docker container and orchestrated with Docker Compose. A 42 school project.
`Docker` `NGINX` `MariaDB` · *Infrastructure, service isolation, configuration*

### ⚔️ [Corewar](https://github.com/harmonie-durrant/corewar) & 🗡️ [myrpg](https://github.com/harmonie-durrant/myrpg)
Corewar recreates the classic programming game as an assembler plus a virtual machine. myrpg is a 2D RPG built on a custom Entity Component System, with its own physics and collision handling.
`C` `CSFML` · *Low-level architecture, building engines from scratch*
